# Foodix Backend Scaffold

Reserved for the Spring Boot backend.

Recommended package structure:

```text
com.foodix
├── config
├── controller
├── dto
├── entity
├── exception
├── repository
├── security
└── service
```

Recommended stack:

- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security + JWT
- Bean Validation
- MySQL or PostgreSQL
- Flyway or Liquibase
- OpenAPI / Swagger

Suggested API prefix: `/api/v1`
